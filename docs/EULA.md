## 3. What the Software does to your system

The Software reads and, **only when you explicitly confirm by pressing a key**, modifies
`~/.claude/settings.json` in order to register Claude Code hooks. It backs the file up before any
change and can remove its own entries again. It also writes files under `~/.claude/keypad/`. See
[PRIVACY.md](PRIVACY.md) for the complete list.
